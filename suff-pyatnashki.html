Время викторины!

Как играть

1. По очереди открывайте по две карточки, чтобы найти пары.

2. Когда найдете пару, ответьте на вопрос викторины.

3. Правильный ответ = 1 очко и продолжение хода.

4. Неправильный ответ = 0 очков, ход переходит другому игроку.

5. Игра состоит из 4 раундов. Побеждает игрок с наибольшим количеством очков!
