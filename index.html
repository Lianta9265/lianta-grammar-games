Как добавить свои игры

Чтобы добавить свои игры в галерею, отредактируйте массив gamesData в разделе JavaScript этого файла.

Каждая игра должна иметь следующие поля:

  • id — уникальный идентификатор
  • title — название игры
  • preview — URL изображения превью
  • url — URL игры для загрузки в iframe
  • tags — массив тегов (строки)
